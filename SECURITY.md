# Security

Please report a vulnerability privately through GitHub: on this repository's **Security** tab, choose **Report a vulnerability**. Do not open a public issue for it.

Include what you found, how to reproduce it, and what an attacker could do with it. You will get a reply within a week.

## What is in scope

- The site at https://jazzpeh.github.io/hawkergowhere/ and the code in this repository.
- The build and deploy workflows in `.github/workflows/`.

The site has no server, accounts or stored personal data. It holds one secret, the data.gov.sg API key, which lives only in GitHub Actions secrets.
